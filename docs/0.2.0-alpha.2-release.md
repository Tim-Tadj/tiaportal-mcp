# TIA Portal MCP 0.2.0-alpha.2

26 November 2026. Experimental unsigned Windows x64 prerelease.

## TIA Portal V20

- Both profiles include exact V17 to V20 workers. The broker loads the worker
  for the selected TIA Portal installation, and each worker loads Siemens
  Openness assemblies locally.
- V20 ReadWrite adds four SIMATIC SD tools for importing and exporting
  `.s7dcl` and `.s7res` documents. The V20 Read profile provides inspection.
- Select `V20` explicitly when V19 and V20 are installed side by side. TIA
  Portal may ask you to approve the new worker when it first attaches.
- V21 requires a dedicated adapter.

## Downloads and installation

Download the Read or ReadWrite Windows ZIP for Codex, VS Code or another local
stdio client. Choose the matching MCPB for Claude Desktop. The release also
provides the manifest and SHA-256 checksums.

For Codex, extract the ZIP to a permanent folder and register the broker with
`--tia-version V20`. See the [installation guide](https://github.com/Tim-Tadj/tiaportal-mcp/blob/0.2.0-alpha.2/README.md#installation)
for the command, prerequisites and connection sequence.

## Validation

- Both profiles built successfully for V17 to V20. The ZIP and MCPB packages
  were assembled without Siemens runtime DLLs.
- The V20 ReadWrite release worker started through Codex, advertised all four
  SIMATIC SD tools and attached to an open project. The check read the project
  identity without making changes. Earlier development checks also verified
  startup and project attachment in Read.
- Full licensed engineering workflow qualification, including SIMATIC SD
  import and export, remains open. The release manifest retains
  `runtimeValidated=false`.
