# 0.2.0-alpha.1 release

23 November 2026. Experimental unsigned Windows x64 prerelease.

## Worker changes

- `GetOpennessStatus` reports effective group membership and saved application
  trust on V19. Siemens may require a fresh approval for a rebuilt or moved
  worker. An unchanged, trusted worker can reconnect with ordinary user rights.
- `ListWatchTables`, `ExportWatchTable` and `ImportWatchTable` cover offline
  watch tables. Replacement is explicit and saving remains a separate action.
- Rack operations return canonical paths for plugged modules and preserve an
  unchanged PROFINET name when configuring the address.

## Migration from 0.1.0-alpha.3

Public API schemas remain discoverable. Only operations marked `callable=true`
by `DescribeApiObject` can run through `InvokeApiMethod`. The first reviewed
signature is V19 `PlcWatchTable.Export(FileInfo, ExportOptions)`. Existing scripts
that called arbitrary methods, setters, constructors, actions or event
callbacks must migrate to supported typed workflows or reviewed signatures.
The new minor prerelease series marks this interface change. The installation
and client configuration format continue to use the existing broker and profiles.

## Packages and evidence

- Both Read and ReadWrite bundle exact V17, V18 and V19 workers. V20 is deferred.
  V21 requires a dedicated adapter.
- Local V19 development-build qualification exercised the five-slot offline
  rack and the 56-row watch-table round trip on a disposable project. Hardware
  compilation returned zero errors and 26 warnings. The same trusted worker
  attached from two fresh processes without a repeat prompt.
- The release manifest keeps `runtimeValidated=false` for the full deployment
  and licensed-runtime matrix. No PLC download or physical operation was part
  of the qualification.

The release includes both Windows ZIPs, both Claude Desktop MCPBs, the release
manifest and SHA-256 checksums. The worker loads Siemens assemblies from the
installed TIA Portal.
